Struktur des Werkzeugs

Drei Bausteine: Scan, Sort und Report. Einstieg ist src/cli.ts, Details in der Doku.

  • Scan — liest das Verzeichnis rekursiv.
  • Sort — gruppiert nach Jahr/Monat.
Pfade mit Leerzeichen immer quoten.
// Einstiegspunkt
export function main(argv: string[]): number {
  report(sortByDate(scan(argv[0] ?? '.')));
  return 0;
}
