Bau mir eine kleine CLI, die Dateien nach Datum sortiert, und erklaer mir die Struktur.

Struktur des Werkzeugs

Ich lege drei kleine Bausteine an: Scan, Sort und Report. Der Einstiegspunkt ist src/cli.ts, die Logik liegt in src/lib/. Details stehen in der Projekt-Doku.

  • Scan – liest das Verzeichnis rekursiv ein.
  • Sort – gruppiert nach Jahr/Monat.
  • Report – schreibt eine lesbare Zusammenfassung.
Hinweis: Pfade mit Leerzeichen immer quoten, sonst bricht der Aufruf unter Windows.
pwsh · erfolgreich · 0,8 s
node .\src\cli.ts --dir "C:\Fotos" --dry-run
src/cli.ts
// Einstiegspunkt der Sortier-CLI
export function main(argv: string[]): number {
  const dir = argv[0] ?? '.';
  const files = scan(dir);
  report(sortByDate(files));
  return 0;
}
